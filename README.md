## Правило

Сотрудника можно назначить исполнителем задачи только если он состоит в участниках проекта этой задачи.

## Структура

- `db/` — SQL-скрипты (исходная схема, seed, исправленная схема, тесты)
- `report/` — отчёт `.docx`
- `docs/` — ER-диаграмма и скриншоты
- `answer/` — бланк ответа команды

## Как запускать тесты

1. Создать БД `db04_before`, выполнить `db/schema.sql` и `db/seed.sql`.
2. Выполнить `db/DB04_контрпример_исходная_схема.sql` — вернёт одну строку (правило не enforced).
3. Создать БД `db04_after`, выполнить `db/DB04_исправленная_пустая_схема.sql`.
4. Выполнить `db/DB04_тест_итоговая_схема.sql` — в Messages будет `ALL TESTS PASSED`.
